Browser Security Restriction (HTTP vs HTTPS):

Mobile browsers (Chrome / Safari) disable microphone and Web Speech API on local Wi-Fi IP connections (http://192.168.x.x) because it is not an encrypted HTTPS link.

💡 Recommended Workflow (Zero Setup):

Aapko phone ka mic use karne ki zaroorat nahi hai! Laptop/PC me Loopback Audio already interviewer ki voice (Teams/Zoom/Meet) direct speaker se capture karta hai, aur answers phone screen par live stream ho jate hain.

🔧 Agar Phone Mic hi use karna ho (Chrome Android):
  1. Chrome me new tab me open karein: chrome://flags
  2. Search karein: Insecure origins treated as secure
  3. Is box me enter karein: http://...:8000
  4. Dropdown ko Enabled karein aur Chrome ko Relaunch karein. Phone mic turant enable ho jayega!
